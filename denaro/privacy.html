Privacy Policy - Denaro App

Ultimo aggiornamento: Dicembre 2024

In sintesi: Denaro è un'app completamente offline. Non raccogliamo, trasmettiamo o condividiamo alcun dato personale. Tutti i tuoi dati finanziari rimangono esclusivamente sul tuo dispositivo.

1. Chi siamo

Denaro è un'applicazione mobile per la gestione delle finanze personali progettata per funzionare completamente offline. L'app è sviluppata con l'obiettivo di garantire la massima privacy e sicurezza dei dati degli utenti.

2. Dati che NON raccogliamo

Denaro è progettata per essere completamente offline. Non raccogliamo, trasmettiamo, condividiamo o vendiamo:

  • Informazioni finanziarie (bilanci, transazioni, bucket)
  • Dati personali identificabili
  • Informazioni di utilizzo dell'app
  • Dati di localizzazione
  • Informazioni del dispositivo
  • Dati biometrici o PIN di sicurezza
  • Preferenze linguistiche o altre impostazioni

3. Dove vengono archiviati i tuoi dati

Tutti i dati che inserisci in Denaro vengono archiviati esclusivamente:

  • Sul tuo dispositivo locale in un database SQLite crittografato
  • Nella memoria sicura del dispositivo per le impostazioni di sicurezza (PIN)
  • Nello storage locale dell'app per le preferenze (lingua, tema)

Non utilizziamo server cloud, servizi di backup automatici o database remoti.

4. Sicurezza dei dati

I tuoi dati sono protetti attraverso:

  • Crittografia del database: il database SQLite è crittografato con chiavi generate casualmente
  • Autenticazione locale: PIN e autenticazione biometrica gestiti esclusivamente dal sistema operativo
  • Isolamento dell'app: i dati sono accessibili solo dall'app Denaro sul tuo dispositivo
  • Nessuna trasmissione di rete: l'app non invia mai dati via internet

5. Funzionalità di sicurezza opzionali

L'app offre funzionalità di sicurezza opzionali:

  • PIN di accesso: memorizzato in modo sicuro sul dispositivo tramite Expo SecureStore
  • Autenticazione biometrica: gestita direttamente dal sistema operativo del dispositivo

Questi dati di sicurezza non vengono mai trasmessi o condivisi.

6. Autorizzazioni dell'app

Denaro richiede solo le autorizzazioni minime necessarie:

  • Archiviazione locale: per salvare i dati finanziari sul dispositivo
  • Autenticazione biometrica (opzionale): se scegli di attivare questa funzionalità

Non richiediamo accesso a contatti, fotocamera, microfono, posizione o altri dati sensibili.

7. Backup e sincronizzazione

Denaro non offre funzionalità di backup cloud o sincronizzazione automatica. Sei responsabile del backup dei tuoi dati attraverso:

  • Backup del dispositivo (se supportato dal sistema operativo)
  • Futuri strumenti di esportazione che potremmo aggiungere

8. Servizi di terze parti

Denaro non integra servizi di analytics, pubblicità o altri servizi di terze parti che potrebbero raccogliere dati. L'app è completamente autonoma.

9. Diritti dell'utente

Poiché non raccogliamo dati personali, hai sempre il controllo completo:

  • Accesso: tutti i tuoi dati sono visibili nell'app
  • Modifica: puoi modificare o eliminare qualsiasi dato direttamente nell'app
  • Cancellazione: disinstallando l'app rimuovi tutti i dati associati
  • Portabilità: i tuoi dati rimangono sul tuo dispositivo

10. Modifiche a questa Privacy Policy

Eventuali modifiche a questa privacy policy saranno comunicate attraverso:

  • Aggiornamenti dell'app negli store
  • Notifiche nell'app (se implementate)
  • Pubblicazione della versione aggiornata

11. Conformità normativa

Denaro è progettata per essere conforme a:

  • GDPR (Regolamento Generale sulla Protezione dei Dati)
  • CCPA (California Consumer Privacy Act)
  • Altre normative sulla privacy

La conformità è facilitata dal fatto che non raccogliamo dati personali.
